How this site was built

Built with Claude Code, using the same workflow described in the Experience panel: I set the plan (structure, content, style direction) and reviewed it before anything was written; the page was implemented against that plan; I reviewed the actual diff and the rendered result before treating anything as done.

Deliberately simple: plain HTML/CSS, no build step, no JavaScript dependency for content — the dashboard panels render directly from HTML, so there's no "script failed to load" failure mode. Hosted on GitHub Pages, source at github.com/Akkumag/akkumag.github.io.
